# 基于极小极大算法的AI井字棋网页项目

## 项目介绍
本项目是《人工智能导论》课程期末作业，实现了一个基于极小极大算法的网页版AI井字棋游戏。项目采用纯前端HTML/CSS/JavaScript开发，无需后端环境，浏览器直接打开即可运行。项目结合了经典AI搜索算法与人机交互设计，实现了多难度等级的智能对战功能。

## 核心功能
1. **人机对战**：玩家执O，AI执X，双方轮流落子，率先连成三子者获胜
2. **三档难度调节**：提供简单、中等、困难三种难度，困难模式采用极小极大最优算法，AI不败
3. **悔棋功能**：支持撤销上一步操作，可回退至对局开始状态
4. **胜负统计**：自动记录玩家胜、AI胜、平局的局数，实时更新计分板

## 运行环境
- 操作系统：Windows / macOS / Linux 均可
- 浏览器：Chrome、Edge、Firefox、Safari等主流现代浏览器
- 无需安装额外依赖、无需配置服务器环境

## 运行方式
1. 将项目代码下载至本地
2. 直接双击 `index.html` 文件，在浏览器中打开
3. 选择难度后点击棋盘格子即可开始游戏
